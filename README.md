# Side Hero

Idle RPG HTML5 para **itch.io**.

## Desenvolvimento

```bash
npm install --cache ./.npm-cache
npm run build
```

Abra `dist/index.html` no navegador (ou sirva a pasta `dist/`). O zip de publicação é `npm run release` — só quando for gerar uma build para o itch.

## Fonte de verdade

- `specs/` — specs SDD por feature
- `.cursor/AGENTS.md` — agents, skills e rules do projeto
- `releases/` — zips gerados sob pedido
